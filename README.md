
# Compensar Store - Aplicación Móvil Híbrida

Aplicación móvil híbrida desarrollada con Ionic/Angular para Compensar.

## Características

- Autenticación completa (login/registro)
- Catálogo de productos con API
- Carrito de compras funcional
- Almacenamiento local
- Diseño responsive

## Tecnologías

- Ionic 7
- Angular 17
- TypeScript
- Capacitor

## Instalación
```bash
npm install
ionic serve
